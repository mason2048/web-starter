## 设计方向

- 关键词：专业、克制、清爽、可靠。
- 内容背景使用纯白或极浅冷灰，不使用米色、奶油色和玻璃拟态。
- 深海军蓝侧边栏提供稳定的产品框架；青绿色只用于主操作、选中态和关键数字。
- 数据密集页面以表格、工具栏和抽屉为主，不改造成卡片网格。
- 不使用装饰性徽章、营销口号、无意义的指标和渐变光晕。

## 字体与密度

- 中文字体：`Inter, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 页面标题：30–34px / 700；移动端 24–28px。
- 区块标题：18–20px / 600。
- 正文和表单：14–16px；表格内容默认 14px。
- 侧边栏宽度约 224px；顶部栏高度约 64px。
- 页面水平留白桌面端 32–40px，移动端 16px。
- 常规圆角 8px，抽屉与大型弹层不超过 12px。

## 组件规则

- App Shell：固定侧边栏、顶部工具栏、可滚动主区域。
- 侧边栏：图标使用同一套线性图标，选中态为青绿色底色，不增加发光。
- 表格：细边框、明确表头、稳定列宽，操作列使用文字按钮。
- 筛选栏：搜索、状态、刷新保持单行；小屏幕允许自然换行。
- 表单：创建和编辑优先使用右侧抽屉，危险操作使用确认对话框。
- 状态：低饱和语义色，不能只用颜色表达含义。
- 焦点：所有键盘可操作控件必须具有清晰的 focus-visible 状态。

## 核心交互

1. 用户登录后进入概览或原目标页面。
2. 项目列表支持搜索、状态筛选、分页和刷新。
3. 新建或编辑项目在抽屉中完成，校验错误就地显示。
4. 删除操作二次确认，成功后刷新列表并显示反馈。
5. 无权限菜单不显示；直接访问无权限路由时展示 403 页面。
6. 会话失效统一返回登录页，并保留可恢复的目标地址。

## 响应式

- `>= 1200px`：完整侧边栏和表格布局。
- `768–1199px`：侧边栏可折叠，表格允许水平滚动。
- `< 768px`：侧边栏改为抽屉，页面工具栏换行，表单抽屉占满屏幕。
